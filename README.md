# 课表转日历（网页版）

> 粘贴课表 / 上传 Excel / 上传 PDF → 一键生成手机日历可导入的 `.ics` 文件。
> **苹果、安卓通用，不用装任何软件，手机浏览器打开就能用。**

在线使用：**https://xiongxiangyu2778.github.io/timetable-to-calendar/**

## 四种输入方式

| 方式 | 适合 | 准确率 |
|---|---|---|
| **智能粘贴** | 从教务系统全选复制 | 高（自动识别星期/节次/周次） |
| **上传 Excel / CSV** | 教务系统能导出表格 | 最高（不经过 OCR，零误差） |
| **上传 PDF** | 手上只有 PDF 课表 | 高（解析文字层，扫描件不支持） |
| **手动编辑** | 其他情况 | 自己把关 |

不管用哪种方式，解析完都会进入一个**可编辑的核对表格**，确认无误再生成日历。

## 为什么做这个

开学最烦的两件事：手动把课表一节节敲进手机日历、单双周记混走错教室。

这个小工具把两步合成一步：导入课表 → 生成 `.ics` → 手机日历一键导入。
每条日程提前 15 分钟提醒，教室写在备注里。

## 支持的课表格式

**粘贴文本**支持：

```
高等数学 | 周一 | 1-2 | 1-16 | 教1-101 | 张老师     ← 竖线分隔
高等数学 周一 1-2节 1-16周 教1-101 张老师            ← 空格分隔
```

- 星期：`周一` / `星期一` / `1`
- 节次：`1-2`、`第1-2节`、`第一二节`
- 周次：`1-16`、`1-16周`、`1-15单周`、`2-16双`、`1-4,6,8,10,12(周)`

**Excel/CSV** 支持两种表头：

1. **列表式**：`课程名称 / 星期 / 节次 / 周次 / 教室 / 教师`
2. **网格式**：第一行 `星期一~星期日`，第一列节次，和教务系统导出的课表一样

**PDF**：直接传教务系统打印出来的课表 PDF 即可，会自动抓文字层、按坐标还原表格。

- 需要「能选中文字」的 PDF（文字层）；扫描件 / 图片版 PDF 读不出内容，页面会提示
- 遇到扫描件：用 WPS「另存为 Excel」，或截图后用**粘贴**方式
- 老式 PDF 若结构特殊认不出，同样退回 Excel / 粘贴两条路

## 导入方法

| 设备 | 步骤 |
|---|---|
| **iPhone** | 下载后点开 → 右上角「…」→ 用其他应用打开 → 选「日历」→ 全部添加 |
| **安卓** | 下载后点开 → 选「日历」导入；或在日历 App 里找「导入日程」 |
| **Google 日历** | 网页版 calendar.google.com → 设置 → 导入和导出 → 选 `.ics` |
| **Windows / Mac** | 双击 `.ics` → 自动导入系统日历 |

建议先建一个叫「课表」的日历分组再导入，课表变了可以整组删除重导。

## 技术说明

- 单文件纯前端（HTML + 原生 JS）；Excel 解析用本地打包的 SheetJS，PDF 解析用本地打包的 pdf.js，不联网也能用
- 生成的 `.ics` 遵循 RFC 5545：CRLF 换行、75 字节折行、UTF-8
- 时间统一按北京时间换算成 **UTC（带 Z 后缀）**写入，任何日历 App 都能正确还原，跨时区也不会偏移
- 所有计算都在浏览器本地完成，**不上传任何数据**
