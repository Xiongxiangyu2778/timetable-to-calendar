# 课表转日历（网页版）

> 粘贴课表 → 一键生成手机日历可导入的 `.ics` 文件。
> **苹果、安卓通用，不用装任何软件，手机浏览器打开就能用。**

在线使用：**https://xiongxiangyu2778.github.io/timetable-to-calendar/**

## 为什么做这个

开学最烦的两件事：手动把课表一节节敲进手机日历、单双周记混走错教室。

这个小工具把两步合成一步：

1. 从教务系统把课表按格式抄进来（一行一门课）
2. 点一下生成，下载 `.ics`，手机日历一键导入

生成的每条日程都会提前 15 分钟提醒，教室写在备注里。

## 课表格式

```
高等数学 | 周一 | 1-2 | 1-16 | 教1-101 | 张老师
大学英语 | 周二 | 3-4 | 1-16单 | 外语楼203 | 李老师
体育（篮球） | 周三 | 5-6 | 2-16双 | 体育馆 | 王老师
```

| 字段 | 说明 |
|---|---|
| 课程名 | 必填 |
| 星期 | `周一` / `星期一` / `1` 都行 |
| 节次 | `1-2`（连堂）、`3,4`、`5` |
| 周次 | `1-16`（每周）、`1-16单`（单周）、`2-16双`（双周）、`1,3,5,7` |
| 教室 | 可留空 |
| 教师 | 可留空 |

> 分隔符 `|` 必须保留；以 `#` 开头的行会被忽略。

## 导入方法

| 设备 | 步骤 |
|---|---|
| **iPhone** | 下载后点开 → 右上角「…」→ 用其他应用打开 → 选「日历」→ 全部添加 |
| **安卓** | 下载后点开 → 选「日历」导入；或在日历 App 里找「导入日程」 |
| **Google 日历** | 网页版 calendar.google.com → 设置 → 导入和导出 → 选 `.ics` |
| **Windows / Mac** | 双击 `.ics` → 自动导入系统日历 |

建议先建一个叫「课表」的日历分组再导入，课表变了可以整组删除重导。

## 技术说明

- 单文件纯前端（HTML + 原生 JS），零依赖、可离线使用
- 生成的 `.ics` 遵循 RFC 5545：CRLF 换行、75 字节折行、UTF-8
- 采用浮动本地时间，不做时区换算，跨时区也不会错
- 所有计算都在浏览器本地完成，**不上传任何数据**
