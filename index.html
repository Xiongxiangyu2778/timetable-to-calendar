课表转日历

粘贴文字 / 上传 Excel → 生成 .ics → 手机日历一键导入

粘贴课表文字
上传 Excel / CSV

支持三种写法：| 分隔、空格/制表符分隔、整页课表复制（自动识别星期和节次）

点击选择文件 或把文件拖到这里
支持 .xlsx / .xls / .csv / .pdf

Excel 支持两种表头：星期×节次网格（教务系统导出）或 课程名/星期/节次/周次/教室/教师 列表；PDF 需是能选中文字的（扫描件/图片版不支持）

核对课表 （可以直接改，改完再生成）

课程星期 节次周次 教室教师

表格可以左右滑动，查看教室、教师等完整列

没有自动下载？点这里下载 我的课表.ics

导入方法（iPhone / 安卓）

iPhone：下载后点开 → 右上角「…」→ 用其他应用打开 → 选「日历」→ 全部添加。

安卓：下载后点开 → 选「日历」导入；或在日历 App 里找「导入日程」。

Google 日历：网页版 calendar.google.com → 设置 → 导入和导出 → 选 .ics。

建议：先建一个叫「课表」的日历分组再导入，以后整组删除重导不会弄乱别的日程。

课表从哪来？

三种都行：① 教务系统「我的课表」页面直接全选复制粘贴；② 导出 Excel/CSV 后上传；③ 按格式手写。

所有解析都在浏览器本地完成，不上传任何数据。
